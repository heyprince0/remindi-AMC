1

Click Install. Remindi opens in its own window and sends desktop notifications.

All Platforms

Detailed Steps for Every Device

🤖

Android

Works on all Android devices with Chrome 76+. Supports home screen install and offline access.

  • Open Chrome → app.remindi.online
  • Tap ⋮ menu → "Add to Home screen"
  • Tap Install on the popup → done
🍎

iPhone & iPad

iOS 16.4+ supports full PWA. Must use Safari — Chrome on iOS does not support install.

  • Open Safari → app.remindi.online
  • Tap Share button (box with up arrow)
  • Tap "Add to Home Screen" → Add
🪟

Windows PC

Install via Chrome or Edge on Windows 10/11. Runs as a standalone window.

  • Open Chrome or Edge → app.remindi.online
  • Click the install icon (⬇) in the address bar
  • Click Install → Remindi opens
🍏

Mac

Works on macOS 10.15+ via Chrome or Edge. Appears in your Launchpad and Dock.

  • Open Chrome or Edge → app.remindi.online
  • Click the ⬇ icon in the address bar
  • Click Install → pin to Dock
